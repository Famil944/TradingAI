# Основные уведомления: только Боллинджер ×3

С 16 ноября 2026. Код версии bollinger-live-three-attempts-v1. Старые источники отключены для новых отправок; их история и расчёт уже открытых результатов сохранены.

Одна карточка содержит пару, направление и три времени входа. После первой WIN остальные попытки отменены. Повтор допускается только после LOSS; DRAW/UNKNOWN завершает цикл отдельно, без придумывания выигрыша или проигрыша. Реальных ставок и автоматических сделок нет; денежный учёт только виртуальный.

План отправляется за 15–20 секунд до первого входа. Повторные времена известны заранее: для M5 12:00, 12:05, 12:10; окончание третьей попытки 12:15. Обновление результата приходит после получения тика и не является предварительным сигналом для следующей границы. Пользователь видит условный план заранее.

Правило: SMA20 ± 2 стандартных отклонения по закрытым свечам. Касание только верхней полосы максимумом → DOWN; только нижней минимумом → UP. Касание обеих → пропуск. Анализ M1 для M2, M5 для M5, M15 для M15. Последняя формирующаяся свеча не используется.

Сэмплируются цены начала и конца каждого интервала: первый полученный тик с временем события и получения в пределах 2 секунд после границы. Пропуск означает UNKNOWN, а не восстановленную задним числом цену. Исторические фоновые циклы могли считаться WIN при поздней известной победе после пропущенного исхода; реальные уведомления останавливаются на UNKNOWN. Эти статистики не смешиваются.

Один активный цикл на экспирацию, без наложения циклов одной пары до конца исходного трёхпопыточного окна, пауза 60 секунд после завершения, 5 минут на пару после полного LOSS. Для одинаковой пары/времени выбирается один вариант: выше выплата, затем длиннее период. Это фиксированное правило, а не оценка вероятности.

Винрейт реальных циклов хранится отдельно в data/bollinger-cycles.db. Статистика показывает WIN/LOSS, WR, победы на попытках ①/②/③, ничьи, ожидание и неизвестные. Новый журнал начинается с нуля; старые цифры 90–100% не переносятся. /otc — компактное меню; /otc_stats — циклы.

Дополнительно разработаны журнал отклонённых XGBoost-прогнозов, готовность данных после разрыва, фоновый маршрутизатор методов и отчёт /otc_validation по дням/версиям с моделированием пауз. В режиме только циклов старые источники и фоновые методы не создают новых наблюдений. Проверка восстановления данных остаётся активной: минимум 10 секунд и 3 свежих тика на пару плюс непрерывные 60 закрытых M1 и свежая выплата.
