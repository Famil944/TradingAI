# Результат рефакторинга

## Обновление: бесплатное тестирование

По последней просьбе владельца добавлен явный тестовый режим с неизвестной выплатой/временем выплаты/открытием. В `.env` включён `OTC_TEST_MODE=true`; секреты и прежние значения сохранены. Для бесплатного тарифа без потока реализованы снимки свечей: один инструмент раз в 300 с, до 12 учитываемых API-запросов за сеанс. В сообщениях явно обозначены неизвестные данные и отсутствие live. Подтверждённое закрытие, устаревшие свечи и недостаток истории по-прежнему дают отказ. Тестовые стратегии учитываются отдельно; исходы UNKNOWN.

Журнал версии 2 хранит неизвестные payout/payout_at как NULL. Переход с версии 1 сохраняет все строки, индексы и триггеры собственной таблицы через атомарную миграцию с backup. Прошли 46 тестов, включая отправку сигнала настоящей стратегии по бесплатному снимку, неизвестную выплату, бюджет/резерв, старые свечи, повторы, строгую политику и миграцию старого журнала. Реальные API и Telegram не проверялись.

Ниже — исходный отчёт до изменения тестовой политики.

## Исходный рефакторинг

Ветка: `codex/otc-only-mvp`. Исходная точка: `6506667`. Изменения только в этом проекте; push, merge и развёртывание не выполнялись.

- Удалены прежние клиенты и сканеры, команды, новости/риски/OCR/экспорты и связанные тесты. Список зафиксирован до удаления в `audit_removal_manifest.json`.
- Сохранена общая защита одного экземпляра. База изменяется добавлением таблиц с backup перед первым обновлением существующего файла; пользовательские таблицы не удаляются. Локальных .env и баз в исходной папке не было; переменные окружения не изменялись.
- Реализованы OTC-меню, owner/callback-проверки, ограниченные сеансы, строгая проверка данных, EMA/RSI/ATR, cooldown, журнал сигналов/отказов/сравнений, виртуальная статистика, UNKNOWN, replay и последовательная проверка по отложенным окнам без настройки параметров.
- Проверены исходники установленного OTCharts 0.7.0 и документация поставщика. Использован его документированный HTTP/SSE контракт с отменяемыми async-операциями. UTC+2 преобразуется только в этом адаптере и проверяется тестами.

**Существенное ограничение:** текущий контракт OTCharts не содержит timestamp выплаты и может не подтверждать открытие Pocket Option. Адаптер блокирует live-сигналы. Нужен документированный доступ к этим подтверждениям и независимая проверка цен платформы. Платный тариф сам по себе это не исправляет. Получение ответа API не считается доказательством свежести выплаты.

Проверки: **33 теста прошли**, включая локальный HTTP/SSE сервер, реальную стратегию с синтетическими тиками, безопасную миграцию и backup, гонки start/stop, watchdog отсутствующей цены экспирации, доступ владельца, UNKNOWN и replay без будущих данных. Ruff, compileall, pip check, Git diff --check, сборка и установка wheel прошли. CLI replay и импорт сравнений проверены на временных синтетических данных. Первая попытка установки без изоляции сборки выявила отсутствие setuptools в чистом venv; штатная установка с изоляцией успешно собрала пакет.

`python main.py` проверен: при отсутствующем TELEGRAM_BOT_TOKEN выдаёт понятное сообщение и код 1. Все три необходимых локальных значения отсутствуют. Authenticated live-проверки Telegram/OTCharts, сравнение с самой платформой, демосчёт и физический Android не проверялись. Прибыльность и win rate не оценивались на реальном рынке.

