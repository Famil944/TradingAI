# TradingAI

Telegram-бот для анализа Binance Spot без доступа к торговому аккаунту и без
автоматического размещения ордеров.

## Возможности

- ручной скан `/scan`: TOP-50 с автоматическим расширением до TOP-100;
- приоритетный автоматический анализ TOP-20 сразу после запуска и по расписанию;
- технический Score, зона входа и единственная цель +3%;
- категории: сильный сигнал, подтверждённый сигнал, ранний вход;
- постоянный журнал выбранных сделок с контролем цели +3%;
- критические уведомления, статистика реальных сделок и Excel-экспорт;
- ручное подтверждение закрытия и уточнение цены входа/суммы позиции;
- отключаемый новостной риск-фильтр CryptoPanic (по умолчанию выключен);
- Telegram-действия: ПОКУПКА, РАННИЙ ВХОД, НЕ ПОКУПАТЬ, СИГНАЛ ВЫХОДА;
- SQLite для настроек, сигналов и сделок с восстановлением после перезапуска;
- защита от второго экземпляра и Windows-supervisor.
- обязательные фильтры ликвидности, спреда, объёма, тренда, пампа и
  свободного пространства до цели;
- безопасный диагностический JSON по команде `/diagnostics` для последующего
  улучшения стратегии.

Бот не является финансовым советником и не гарантирует результат сделки.

## Установка

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Заполните `.env` локально. Не публикуйте этот файл и не отправляйте токены в
чатах или скриншотах.

```env
TELEGRAM_BOT_TOKEN=...
CRYPTOPANIC_AUTH_TOKEN=...
```

## Запуск

```powershell
python main.py
```

Для Windows предусмотрен `run_bot_forever.ps1`, который перезапускает процесс
после сбоя. `start_trading_ai_bot.cmd` используется для автозагрузки.

## Команды

- `/start` — регистрация и главное меню;
- `/scan` — анализ рынка;
- `/signals` — свежие сигналы;
- `/top` — рейтинг по Score;
- `/coin SOL` — анализ отдельной пары;
- `/stats` — статистика;
- `/history` — история сигналов;
- `/settings` — текущие настройки.

## Новостной фильтр

Фильтр не пересылает статьи. Он используется только для решения:

- `BUY` — технический сигнал подтверждён, критического риска нет;
- `EARLY_BUY` — Score 65-74 и положительный фон;
- `AVOID` — обнаружен критический риск;
- `WAIT` — данных недостаточно или вход не подтверждён.

Если CryptoPanic недоступен или токен не имеет API-доступа, фильтр работает по
принципу fail-closed: автоматический BUY не отправляется.

## Проверка

```powershell
python -m unittest discover -s tests -v
python preflight_news.py
```
### Диагностика стратегии

Команда `/diagnostics` скачивает JSON-отчёт с итогами последнего скана,
причинами отсева монет и обезличенными параметрами сделок. Telegram-токен,
API-ключи, `.env` и chat id в отчёт не включаются.
