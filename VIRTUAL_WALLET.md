# Виртуальный счёт и фон ×3

Счёт Основного Боллинджера ×3: начальные 5000 ₽, ставки 100 / 250 / 625 ₽, прибыль WIN 92% ставки. Итог цикла при победе на попытке 1/2/3: +92 / +130 / +225 ₽; три LOSS: −975 ₽. Это симуляция, без брокерских заявок. Старые сигналы в баланс не переносятся.

В `/otc` → «Виртуальный баланс» (или `/virtual`) можно менять текущий баланс, три ставки и выплату. Изменения ставок/выплаты применяются к новым циклам; открытые сохраняют прежние параметры. Ручные изменения баланса показываются отдельно от торгового результата. Данные сохраняются в `data/virtual-wallet.db`; повторная обработка исхода не меняет баланс дважды.

На новый цикл резервируется сумма всех трёх ставок. При недостатке свободных средств виртуальный цикл пропускается, уведомления продолжаются. DRAW возвращает резерв, UNKNOWN замораживает ставку неизвестной попытки и прекращает цикл; известные убытки сохраняются. Поэтому прибыль при UNKNOWN неполна.

В `/otc` → «Фон ×3» доступны три независимых метода на каждом M2/M5/M15: возврат внутрь полос Боллинджера без RSI, пробой с ретестом, откат EMA9/19. Всего девять вариантов. Фон не затрагивает виртуальный баланс и не отправляет основные сигналы. Для M2 анализируются закрытые M1, для остальных — соответствующие свечи.

У каждого варианта до трёх последовательных попыток в одном направлении. После WIN/DRAW/UNKNOWN остановка; только LOSS позволяет следующую попытку. Отчёт показывает WR, победы на ①/②/③, ничьи, ожидание и пропуски данных. Исторические одиночные исходы не перенесены. Новые наблюдения хранятся в `data/community-cycles.db`; прежние фоновые эксперименты остаются отключены.
