# TradingAI: приватная Telegram Mini App (исследовательская панель)

Включает только чтение — никаких операций с бинарными опционами, паролей Pocket Option или доступа к торговле.

## Что уже работает в коде

- Статус подключения и возраст последней котировки
- Сигналы и виртуальная статистика по **Основной / XGBoost / Groq**
- Причины через Telegram-команды `/otc_filters 7d` и `/otc_compare 7d`
- Проверка `Telegram.WebApp.initData` на сервере (HMAC SHA256, TTL 1 ч, только указанный `OTC_ADMIN_CHAT_ID`)
- API возвращает только разрешённые поля и не показывает секретные ключи
- HTTP-сервер слушает **127.0.0.1:8091** и не доступен напрямую из интернета

## Настройка (дополнительная; требует домен/HTTPS-прокси)

1. Настрой надёжный HTTPS reverse proxy / tunnel с собственным доменом, ведущий на `http://127.0.0.1:8091`. URL должен быть доступен по HTTPS **через Telegram**, без рекламы или промежуточного логина, который ломает JS.
2. В локальный `.env` добавь:
   ```dotenv
   OTC_MINI_APP_ENABLED=true
   OTC_MINI_APP_PORT=8091
   OTC_MINI_APP_URL=https://your-private-domain.example
   ```
3. Перезапусти бота и открой `/otc_panel` в личном чате с ботом.
4. Открывай Mini App только через Telegram, чтобы приложение получило подписанные `initData`. Просто открытие ссылки браузером показывает только экран без личной статистики.

**Не публикуй** токен, `.env`, временные tunnel URLs с токенами или внутренние базы. Не направляй запросы прямо на HTTP в открытом интернете. Render background worker из `render.yaml` не предоставляет публичный HTTPS URL для Mini App автоматически. Нужен отдельный reverse proxy или веб-сервис с доступом к данным (сейчас не реализован).

## Сигналы M5/M15

Оба таймфрейма допускаются только тогда, когда запланированное время входа совпадает с границей новой **5- или 15-минутной свечи** UTC/МСК. Отправка — за 15–20 секунд до границы. Для расчёта используются только полностью закрытые свечи на момент анализа. Текущая свеча M5/M15 **ещё не закрыта** за 20 секунд до её конца, поэтому она не используется как подтверждённая. При отсутствии истории или наличии задержек бот пропускает сигнал.

Это снижает количество сигналов; предполагаемое повышение их точности следует проверить статистически. Реальные цены Pocket Option сверяются отдельно пользователем.
