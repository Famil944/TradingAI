# TradingAI — четыре равноправные стратегии и компактное меню

Ветка: codex/otc-only-mvp после слияния изменений.

## Четыре стратегии

1. Боллинджер ×3 — исходный прогноз, личный виртуальный счёт владельца **не изменялся**.
2. Боллинджер — возврат внутрь.
3. Пробой и ретест.
4. Откат EMA9/19.

Все четыре действуют **в одном рабочем сеансе**, когда владелец запустил
«Боллинджер ×3» и выбрал M2/M5/M15. Не нужно запускать «фон» отдельно.
Каждая стратегия формирует только собственные перспективные сигналы,
собственные результаты WIN/LOSS и собственные винрейты A/×3/×6.

Для трёх дополнительных стратегий исходный механизм построения кандидатов
сохранён как *внутренний* источник наблюдений. Он не является рассылкой.
Отдельный публикующий движок выбирает максимум один новый инструмент на
стратегию, экспирацию и время входа, проверяет свежесть и отправляет прогноз
владельцу **до** времени входа. Если отправка не подтверждена или запоздала,
прогноз не засчитывается как опубликованный. Неисполненные исследования и
устаревшие сигналы никогда не подмешиваются к WINRATE этих трёх стратегий.

### Какие исходы учитываются

- A: реальные попытки **прогноза**, у которых есть исход из котировок.
- ×3: три последовательные попытки одного опубликованного сигнала, остановка
  при WIN, DRAW или UNKNOWN.
- ×6: комбинация до двух последовательных ×3 в пределах той же стратегии,
  версии и экспирации; не означает финансовую прибыль.
- UNKNOWN: остаётся неизвестным, если отсутствует подтверждённая цена.
  Разрешено сопоставление точных цен тиков или безошибочных неизменённых
  исторических свечей OTCharts. Нельзя фантазировать исход или использовать
  будущие данные при выборе торгового сигнала.

Отдельные версии алгоритмов и экспирации не смешиваются. Отчёты в канал
после каждых 10 подтверждённых исходов WIN/LOSS используют отдельный
журнал доставки.

## Telegram

**Владелец** (OTC_ADMIN_CHAT_ID): /otc, запуск/остановка, управление
экспирациями, приватный виртуальный счёт, /suggestions. В его меню есть
кнопка «📊 Стратегии».

**Подписчики**: /start включает получение **всех четырёх** новых сигналов
автоматически, когда владелец запустил рабочий сеанс; /signal_stats открывает
общую компактную сводку и четыре кнопки; /suggest позволяет предложить
улучшение; /stop_signals отключает личную рассылку. Подписчики не могут
запускать торговый движок или просматривать административные настройки.

В одном компактном экране показаны четыре стратегии и отдельный WR каждой.
Нажатие на стратегию сразу показывает её статистику; дополнительные
переключатели M2/M5/M15, входы/×3/×6, 10/50/100 и период — под сообщением.
Нет отдельных многоуровневых меню «Фон» и «Тест».

Для канала (необязательно) укажите в **локальном** .env:

    OTC_PUBLIC_CHANNEL_ID=-1001234567890

Добавьте бота администратором канала с правом писать и редактировать.
Канал публикует новые прогнозы всех четырёх стратегий автоматически.
Пользователям достаточно вступить в канал; для личной рассылки
нужно отправить /start. Настройка OTC_PUBLIC_SHADOW_METHODS больше не нужна;
старые исследовательские события в канал не пересылаются.

Все пользовательские и публичные сообщения строятся из разрешённых
полей прогноза: стратегия, символ, направление, время, экспирация и
подтверждённые исходы. Приватные данные виртуального счёта не читаются
новыми модулями и не публикуются.

## Хранение данных

- data/bollinger-cycles.db — первоначальная стратегия ×3.
- data/community-cycles.db — внутренний архив кандидатов и тиков.
- data/community-live.db — **только реально отправленные до входа**
  прогнозы трёх остальных стратегий и подтверждённые результаты.
- data/subscribers.db — подписчики личной Telegram-рассылки.
- data/public-telegram.db — подтверждённая история публикаций канала.
- data/community-feedback.db — личная очередь предложений владельцу.

Программа может автоматически уточнять неизвестный исход из доступных
точных тиков и исторического архива. Если этих цен нет, результат
остаётся UNKNOWN. Нельзя обещать полного восстановления старых файлов
Windows/Termux из GitHub.

## Безопасное обновление Termux

Сначала остановите запущенный экземпляр бота (только один экземпляр
на Telegram-токен). В каталоге ~/TradingAI:

    git branch --show-current
    git status --short
    mkdir -p ~/tradingai-backups
    tar -czf ~/tradingai-backups/backup-$(date +%Y%m%d-%H%M%S).tar.gz .env data

Убедитесь, что архив создался без ошибок. В архиве содержатся секреты,
не отправляйте его в открытый GitHub.

Затем:

    git fetch origin
    git switch codex/otc-only-mvp || git switch --track origin/codex/otc-only-mvp
    git pull --ff-only
    python -m pip install -r requirements.txt
    python -m unittest discover -s tests -v
    python main.py

Проверьте /otc от владельца, затем /signal_stats. Новый алгоритм
не гарантирует непрерывный поток сигналов: сигнал возникает лишь при
соблюдении правил стратегии, свежих котировках, достаточной истории и
подтверждённой своевременной доставке. Telegram, OTCharts и Pocket Option
могут показывать разные котировки; прогнозы НЕ являются исполненными
брокерскими сделками. В случае сетевой потери подтверждения Telegram
абсолютную гарантию отсутствия повторов дать нельзя.
