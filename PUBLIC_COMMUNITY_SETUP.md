# TradingAI — открытая статистика и предложения

Рабочая ветка: feat/public-cycles-feedback-20261117 (от codex/otc-only-mvp).
Используются M2/M5/M15. Модуль личного виртуального счёта и логика
основных прогнозов не редактировались. Основная ветка main не менялась.

## Возможности
- /start: личное административное меню владельца, публичное меню для подписчиков.
- /signal_stats: три независимых вида статистики:
  A — отдельные завершённые попытки, B — сигналы ×3, C — циклы ×6.
- Отдельные версии, экспирации и стратегии. Фоновые стратегии отмечены «ТЕСТ»
  и не выдаются за реально доставленные торговые сигналы.
- /suggest: предложение пользователем в личном чате, без публикации.
- /suggestions: приватная очередь владельца, статусы и ответы через бота.
- Telegram-канал: уведомления и отчёты каждые 10 подтверждённых результатов
  по стратегиям, версиям, экспирациям и метрикам. По умолчанию выключен.

## Настройка Telegram-канала
1. Создайте отдельный канал и дайте боту права на публикацию и редактирование.
2. Получите числовой chat_id канала, начинающийся с -100.
3. Добавьте в ЛОКАЛЬНЫЙ .env строку:
   OTC_PUBLIC_CHANNEL_ID=-1001234567890
4. Перезапустите только один экземпляр бота с этим токеном.
5. Старая история не републикуется; новые сигналы публикуются после запуска.

Три фоновые исследовательские стратегии по умолчанию доступны для просмотра
в меню статистики. Публикацию фоновых тестовых прогнозов в канал при желании
включают отдельной строкой в локальном .env:
OTC_PUBLIC_SHADOW_METHODS=bb_reentry,break_retest,ema_pullback

Публикации фоновых прогнозов обязательно маркируются «ТЕСТ», не как
подтверждённые сделки на Pocket Option.

## Приватность
Публичные сообщения формируются только из разрешённых полей: названия
стратегии, пары, времени, направления, экспирации и исходов.
Личный виртуальный счёт, его баланс, ставки и причины пропуска не читаются
и не публикуются новыми средствами. Прежние приватные сообщения не меняются.
Канал отключён, пока ID не указан явно.

Доставка через Telegram не может гарантировать абсолютное exactly-once
при потере подтверждения на сетевом уровне. Журнал подтверждённых
отправлений хранится отдельно в data/public-telegram.db.
Обратная связь хранится в data/community-feedback.db.

## Исторические отчёты
В папке с локальными базами данных запустите:
python -m scripts.recover_otc_history --root . --output data/exports

Создаются signals.csv и daily.csv (разные A/B/C, дни, версии, экспирации).
Результаты «UNKNOWN» остаются неподтверждёнными. Никаких денежных значений
или данных личного виртуального счёта в экспорт не включается.
GitHub не хранит автоматически файлы баз данных с Windows и Termux.
Для полноценного восстановления старых запусков нужны доступные локальные
базы/логи именно с этих устройств.

## Правила ×6
Два последовательных сигнала ×3 одной версии стратегии, источника
и экспирации могут образовать один статистический цикл ×6. Следующий
сигнал должен появиться после подтверждения полного LOSS первого.
Допустимое ожидание второго — 2 часа. Позднее цикл INCOMPLETE.
Показатели A/B/C самостоятельные; WIN ×6 не означает денежную прибыль.
