# Учёт сигналов и проверка результатов

Счётчик в меню и обычная статистика используют своевременно отправленные
сигналы и время отправки. Начало периода — выбранный период либо последний
сброс статистики, если он позднее. Кнопка «Все экспирации» даёт общий итог.
WIN + LOSS + DRAW + ожидающие + неизвестные должны дать число отправленных.
Отменённые, недоставленные и опоздавшие записи показаны отдельно.

Общий итог может включать разные версии; сравнивать качество следует по
отдельным версиям. /otc_quality показывает сегодняшний отчёт по источникам,
версиям, экспирациям и подтверждениям. Для новых сигналов сохраняются также
версия правил исполнения и способ расчёта. Старые записи не переписываются.

«Циклы ×4» сохранены. В режиме ready это архив условных планов, а не текущие
сигналы Основного. Победа в пределах четырёх попыток считается выигранным
циклом; четыре проигрыша — проигранным. Процент циклов не является процентом
побед отдельных сигналов и не учитывает размеры ставок или прибыль.

## Сверка с платформой

Из корня проекта:

```
python -m services.otc_platform_audit export logs/platform-check.csv
```

Файл создаётся только если ещё не существует. Содержит локальные сигналы,
цены OTCharts и пустые поля platform_entry, platform_expiry, platform_outcome,
note. Время — Unix UTC. Заполнять только по фактической истории платформы,
проверяя совпадение актива, направления, входа и экспирации. Исход: WIN, LOSS
или DRAW. Цены необязательны; если указаны, нужны обе. Не подставлять цены
OTCharts в поля платформы. Сохранять CSV с исходными заголовками, запятой
в качестве разделителя и точкой для дробной части цен.

```
python -m services.otc_platform_audit compare logs/platform-check.csv
```

matched/mismatched — совпадения/расхождения; unverified — не заполнено;
otcharts_unresolved — нет окончательного исхода у бота;
platform_evidence_conflict — введённый исход противоречит введённым ценам.
Инструмент доверяет ручному вводу, не подтверждает его подлинность и никогда
не изменяет журналы бота. Файл хранится локально, не публикуйте историю счёта.

Теневые кандидаты уже записываются отдельно: /otc_research. Это виртуальные
исходы, а не исполненные сделки. Правила отбора не меняются автоматически
по результатам отчёта. Длительное обучение само по себе не подтверждает
преимущество новой модели; независимое сравнение версий остаётся необходимым.
