# Настройка OTC

Актуальная пошаговая инструкция: [README.md](README.md).

Нужны локальные TELEGRAM_BOT_TOKEN, OTCHARTS_API_KEY и положительный OTC_ADMIN_CHAT_ID личного чата. Не пересылайте секреты. Запустите preflight.py, затем main.py.

**Ограничение:** OTCharts 0.7.0 не передаёт timestamp выплаты; открытие Pocket Option может быть неизвестно. Live-сигналы блокируются, пока эти обязательные данные нельзя подтвердить. Доступ к платному потоку не заменяет эти проверки. Реальные сделки бот не открывает.
